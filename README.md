# Опять она?!

Русскоязычный фанатский квиз по игровым появлениям Дебры Уилсон: 12 кадров,
разбор каждого ответа, итоговый вердикт и страница со всей базой ролей и источников.

Живая версия: включается через GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).

## Что здесь лежит

Один файл — `index.html`, 1.4 МБ. Внутри всё: разметка, стили, логика квиза и двенадцать
изображений в виде data-URI. Ни сборки, ни зависимостей, ни сервера не нужно — файл
открывается двойным кликом и работает так же, как на хостинге.

## Приватность

Страница не делает ни одного сетевого запроса после загрузки: нет аналитики, счётчиков,
внешних шрифтов и CDN. Не используются cookie, `localStorage` задействован только для
одной настройки — включено движение или нет. Результат прохождения живёт в памяти вкладки
и пропадает при перезагрузке.

Единственные внешние ссылки — источники под каждым кадром, открываются в новой вкладке
с `rel="noreferrer"`.

## Движение

Анимации по умолчанию следуют системной настройке «уменьшить движение»
(`prefers-reduced-motion`). Переключатель в подвале позволяет зрителю задать своё значение;
выбор запоминается в браузере.

## Исходник

Проект собран из Next.js-версии в `../debra-quiz` (React + Tailwind + shadcn) в один
статический файл. Данные вопросов — `../debra-quiz/lib/questions.json`.

## Права

Неофициальный фанатский проект. Игровые кадры и персонажи принадлежат их правообладателям,
для каждого кадра указан источник изображения и подтверждение роли. Наличие изображений
здесь не означает свободную лицензию на их дальнейшее использование.
